# 666clxn Scene Studio 0.17

Редактор сцен GTA V на базе CodeWalker.

- Персонажи, машины, рисунки, метки и сохранение проектов `.clxn`.
- Пролётки камеры и экспорт MP4.
- Тёмная и светлая темы.
- Зоны MCL и каптов в 3D, подписи в пределах 500 м от камеры.
- 14 капт-зон и 318 подписей по Mitsuki Hub; привязка изображений приблизительная.

Готовая Windows x64 сборка размещается в Releases. Распакуйте весь архив и запустите `666clxn.exe`.
Требуется установленная GTA V и .NET Framework 4.8.
